# 🚀 GDG OC BINUS BANDUNG - 27 MEI 2026
## Frontend: Role-Based Access Control (RBAC) Client

Repository ini berisi *source code* bagian antarmuka pengguna (Frontend) untuk sesi *live demo* di acara **Google Developer Groups (GDG) on Campus - BINUS Bandung**.

Proyek ini mendemonstrasikan implementasi keamanan di sisi klien (*Client-Side Security*) menggunakan React, pemisahan UI berdasarkan peran pengguna (RBAC), dan sentralisasi pemanggilan API.

---

## 🛠️ Tech Stack
* **Framework:** React.js (dibuat menggunakan Vite)
* **Language:** TypeScript
* **Routing:** React Router DOM
* **HTTP Client:** Axios
* **State Management:** React Context API

---

## ⚙️ Persiapan (Prerequisites)
Pastikan kamu sudah memiliki [Node.js](https://nodejs.org/) (direkomendasikan versi 18 atau terbaru) terinstal di komputermu sebelum menjalankan proyek ini.
